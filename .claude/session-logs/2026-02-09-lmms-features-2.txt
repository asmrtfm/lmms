     Context

     implemented in TrackOperationsWidget.cpp. Currently, "Export
     pattern..." exports a single PatternTrack to one file, and "Import

      batch operations: export multiple PatternTracks at once to a
     directory, and import multiple .xppt files at once with auto-creation

     Track::Type::Pattern.

     m_trackView->getTrack()).
       - Add QDialogButtonBox with OK/Cancel.
       - If cancelled or nothing checked, return early.
     3. Directory selection — Use FileDialog::getExistingDirectory(this, 
     tr("Export patterns to directory"), "").
       - If empty string returned, return early.
     4. Export loop — For each checked PatternTrack:
       - Get its patternIndex().
       - Build filename: name with spaces replaced by underscores

     QRegularExpression(FILENAME_FILTER), append .xppt.
       - Full path: QDir(directory).filePath(filename).

     DataFile(DataFile::Type::PatternData), iterate
     Engine::patternStore()->tracks(), save state, prune clips to keep only
     the one at targetPos, adjust pos to 0, write file.

     filePath) to avoid duplication.

     4. Rewrite importPattern() (lines 519-633)

     New flow:

     1. Cast m_trackView->getTrack() to PatternTrack* (existing guard).
     2. Multi-file dialog — Change FileDialog::ExistingFile to
     FileDialog::ExistingFiles (plural).
       - Collect QStringList files = ofd.selectedFiles().
       - If empty, return early.
     3. Import loop — Wrap everything in requestChangeInModel() /
     doneChangeInModel():
       - First file (files[0]): import into the right-clicked PatternTrack's
      patternIndex() using existing import logic.
       - Subsequent files (files[1..N]): for each file:
           - Create a new PatternTrack: Track::create(Track::Type::Pattern, 
     Engine::getSong()).
         - Get its pattern index:
     dynamic_cast<PatternTrack*>(newTrack)->patternIndex().
         - Run the same import logic against this new pattern index.

     The inner import logic (lines 537-628 of current code) is extracted
     into a lambda importSingleFile(int patternIndex, const QString& 
     filePath) to avoid duplication.

     4. Post-import cleanup (unchanged): updateComboBox(), setModified().

     5. Filename Edge Case

     If two PatternTracks produce the same sanitized filename, the second
     export would overwrite the first. This is acceptable for the initial
     implementation since PatternTracks typically have unique names.
