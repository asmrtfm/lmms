  InstrumentTracks at a pattern index, rounded up to full bars. For pattern
  index 4, that's 3 bars (from kick02/ride01/sidestick01 which span ~3 bars).

  In LMMS playback, ALL InstrumentTracks in a pattern loop at this shared
  pattern length. So hihat_opened01's note at pos 72 plays only ONCE in a 3-bar

● Here's the summary of the fix:

  Root cause: The repetition period used per-MidiClip length (mClip->length())
  instead of the shared pattern length (PatternStore::lengthOfPattern()). In
  LMMS, all InstrumentTracks in a pattern loop at the same period (the max
  across all tracks). Short clips like hihat (1 bar) and snare (1 bar) were
  being treated as repeating every 1 bar, when actually they only play once in
  the 3-bar pattern cycle. This produced ghost notes at every false repetition.

  Two fixes applied:

  1. Repetition period: Now uses
  Engine::patternStore()->lengthOfPattern(ownerPatternTrackIndex) * ticksPerBar
  — the same shared length the audio engine uses for playback looping.
  2. Step count finalization: Replaced the blanket addSteps() on all tracks with
   type-aware handling — BeatClips get addSteps() only until they reach the
  target length, MelodyClips get updateLength() to recalculate from their notes.

  The build succeeds. You can test with your a.mmp project — the result should
  now match c.mmp.
