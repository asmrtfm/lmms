     Plan: Truncate notes at clip boundary when copying pattern clips to 
     new track

     Context

     The "Copy to New Pattern Track" feature copies MIDI notes from
     selected pattern clips into a new pattern track. When a pattern clip
     is shrunk in the song editor (e.g., from 16 bars to 8 bars), notes
     whose start position falls within the visible range are copied.
     However, if those notes extend beyond the clip boundary, their length
     is not truncated - resulting in a new pattern track that is longer
     than intended.

     File to modify

     src/gui/clips/PatternClipView.cpp - copySelectionToNewPatternTrack()
     method

     Change

     After a note passes the bounds check (line 163) and its position is
     set (line 165), but before it's added to the new clip (line 166),
     truncate the note's length if it extends beyond the clip boundary:

     // Current code (line 163):
     if (newNotePosRelativeToClip < 0 || newNotePosRelativeToClip >=
     clipv->getClip()->length()) { continue; }

     newNote.setPos(newNotePos);
     newMidiClip->addNote(newNote, false);
     maxNotePos = std::max(maxNotePos, newNotePos);

     After newNote.setPos(newNotePos), add:

     // Truncate notes that extend beyond the clip boundary
     TimePos clipEnd = clipv->getClip()->length();
     if (newNotePosRelativeToClip + newNote.length() > clipEnd)
     {
         newNote.setLength(clipEnd - newNotePosRelativeToClip);
     }

     Also update the maxNotePos tracking to account for note end position
     (not just start), so the new pattern track length is correct:

     maxNotePos = std::max(maxNotePos, newNotePos + newNote.length());

     Wait - actually maxNotePos is only used to set the pattern length in
     bars. Since we're truncating notes to fit within the clip, and the
     clip length already determines the bars, this should be fine as-is.
     The current code uses maxNotePos.nextFullBar() to set the clip length
     which rounds up to the next bar. Using note start position is
     sufficient for determining which bar the notes occupy.

       - In the song editor, shrink the pattern clip to 8 bars
       - Right-click and "Copy to New Pattern Track"
       - Open the new pattern in the piano roll - the note should end at
     bar 8, not bar 12
